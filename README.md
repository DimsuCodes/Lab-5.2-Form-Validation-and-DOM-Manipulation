# Lab-5.2-Form-Validation-and-DOM-Manipulation


A registration form with real-time validation built with HTML, CSS, and JavaScript.

## Features
- Error messages that update as you type
- Password match check
- Submit check that moves the cursor to the first invalid field
- Username saved with `localStorage` and filled back in after a refresh

## What I Learned
How to write **one function and reuse it**. `userInput(input, errorSpan)` checks any field I pass it, so I didn't have to write separate code for username, email, and password.
